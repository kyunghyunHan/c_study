🎯 배열과 포인터, 무엇을 가리킬까?

배열 이름과 표현식을 클릭하면 메모리에서 가리키는 대상이 하이라이트됩니다
주황 = 이 표현식은 주소(포인터) → 이 원소를 가리킴 초록 = 이 표현식은 값 → 이 원소의 값 파란 점선 = 포인터가 가리키는 블록(행/면)
int a[5] = {10, 20, 30, 40, 50}; // int = 4바이트, 시작주소 0x1000 가정
메모리 (연속된 정수 5개)
